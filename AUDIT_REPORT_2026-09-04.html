⚠️ 2. Безпека & Access Control

  • ✓ Access Control правильно сконфігурований
    Групи: group_sendpulse_officer (оператор), group_sendpulse_admin (адмін)
    Record Rules: Officer бачить свої чати, Admin бачить все

  • ✓ Password fields правильно позначені

    SendPulse API ID/Secret, Facebook tokens, Anthropic API key
    Всі з password=True захистом
  • 🔴 Webhook NOT захищений HMAC-SHA256
    Очікувано (CLAUDE.md): HMAC-SHA256 підпис验证

    Сценарій атаки: Log injection → витік ключа
    Рішення: Реалізувати HMAC у X-Signature header
  • ✓ Advisory Lock для race-safety
    Partial unique index (sendpulse_contact_id, service) при stage != 'close'
    Advisory lock _SENDPULSE_INBOUND_LOCK_KEY2 = 71234 у webhook-обробці
  • ⚠️ 108 вживань .sudo() — потребує ревізії
    Більшість обґрунтовано (webhook з public auth, config_parameter читання),
    але потребує мінімізації: розподілити дозволи краще через Groups
  • ⚠️ Відсутній audit-лог змін ключів
    ir.config_parameter.sudo().write() не логується, хто коли змінив ключі
🔴 P1 Пріоритет: Заміни webhook token-auth на HMAC-SHA256.
